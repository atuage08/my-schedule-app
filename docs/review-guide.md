# 独立コードレビュー用メモ

## レビュー対象

個人向け「マイスケジュール」の第1段階試作品です。第2回独立レビューの修正対応版（r3）です。名称だけのタスク、週／月カレンダー、下部入力パネル、毎日／毎週／2週間ごと／毎月／毎年の繰り返し、完了取り消し、削除確認を扱います。今回、例外予定の関連付けと全体削除、予定と期限付きタスクの異なる日付マークを追加しました。データはすべて架空で、外部API・通知・同期は未実装です。

このZIPにはソース、スタイル、テスト、ビルド／検査スクリプト、GitHub Actions設定、文書を含めています。node_modules、.git、dist、画像、保存データ、ZIP自身、認証情報・環境設定は含めていません。Git作者・リモート・会話ログも含めません。`REVIEW-MANIFEST.json` に各ファイルのSHA-256があります。

## 再現

Node.js 22以上（推奨24）を使用します。外部パッケージのインストールは不要です。

```sh
node scripts/check.mjs
node --test test/*.test.js
node scripts/build.mjs
```

必要な場合のみ `node server.mjs` でPCの127.0.0.1上にビルド済みdistを表示できます。LANにはバインドしません。GitHubへの送信や公開処理はありません。

## 特に確認してほしい点

1. 選択日と時刻初期値、開始変更時の所要時間維持、終日・複数日の境界。
2. 月末の基準日、未完了繰り越し、「今回だけ／すべて」の編集・削除と完了履歴の整合性。
3. localStorage検証と保存失敗時の復元、複数タブの競合、名称のHTMLエスケープ。
4. Pagesのリポジトリ配下パスでの参照解決、配信・ZIP対象の限定、Actions権限。
5. iPhoneのキーボード、フォームのラベル、片手操作、文字サイズとコントラスト。

Node自動テストは77件（既存56件＋追加21件）です。Asia/Tokyo・UTCそれぞれで成功しています。`scripts/browser-smoke.mjs` はブラウザ操作ツールのTab APIを受け取る関数で、登録・編集・削除確認／キャンセル・復元、例外を含む全体削除、週・月の丸と四角など28項目を確認済みです。単独Node実行ではブラウザを起動しません。ブラウザ操作ツールからモジュールを読み込み、`await runBrowserSmoke(tab)` で再実行します。テストは127.0.0.1の試作品に架空データだけを追加し、自分で作った未完了項目だけを削除します。履歴には取り消し済みの架空データが残ります。GitHub CIでブラウザを動かす設定はまだありません。

最新の変更・互換性の制限は `docs/review2-fixes-report.md`、入力・保存件数の上限と探索方式は `docs/review-fixes-report.md` を参照してください。CodeQLのGitHub上での実行、実際のPagesでの読込、iPhone/Safari実機評価は未実施です。現段階で本番利用の承認は行っていません。

同一Pagesホストの別パスは保存領域のセキュリティ境界になりません。詳細と提案は `docs/pages-preparation.md` を参照してください。
