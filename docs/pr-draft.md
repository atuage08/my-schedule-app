# マイスケジュール第1段階プロトタイプを追加

個人向けカレンダー・ToDoアプリを独立プロジェクトとして追加します。ホームの週／月カレンダー、下部入力パネル、期限あり・期限なしタスク、基本的な繰り返し、完了履歴と復元を実装しています。外部依存・外部APIはなく、架空データを端末内に保存します。
