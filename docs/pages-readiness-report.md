## 保存領域と推奨案

同一Pagesホストの `/karada-log-app/` と `/my-schedule-app/` は同じオリジンで、localStorageの保存領域を共有します。専用キーはアクセス制御ではありません。別アプリのスクリプトやサイトデータ削除の影響を受ける可能性があります。
